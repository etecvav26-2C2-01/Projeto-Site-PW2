# Responsividade com Mobile First

## Porque seguir este modelo?

O site foi pensado e desenvolvido utilizando o conceito Mobile First, pois atualmente grande parte dos acessos a sites acontece por dispositivos móveis.

## Como será feito?

Para isso, serão utilizadas media queries para adaptar o layout de forma coerente a telas maiores, como tablets e desktops.

Os textos serão redimensionados conforme o tamanho da tela, e as imagens utilizarão medidas relativas em porcentagem (%) para melhorar a responsividade.

Além disso, alguns elementos poderão ser ocultados utilizando `display: none;` e flexbox para reorganiza-los, enquanto outros poderão ser exibidos em seu lugar, garantindo uma melhor experiência em diferentes dispositivos.
