# 📋 Estrutura do Site

O site será composto pelas seguintes páginas:

## 🏠 Home

Página inicial do site, onde serão exibidos destaques, produtos em promoção e informações gerais da loja.

## 📃 Produtos (CATÁLOGO)
Página que exibe todos os produtos cadastrados no banco de dados com cards com imagem, nome e preço, botao para adicionar ao carrinho e acesso ao produto individual.

## 🏷 Produto (DETALHES)
Página individual de cada produto que acessa as informacoes do banco de dados atraves do ID fornecido na URL, exibindo o nome do produtoz imagem, descrição, preço e botão "Adicionar ao carrinho".

## 👥️ Sobre

Página com informações sobre a empresa e apresentação da proposta da loja.

## ☎️ Contato

Página destinada à comunicação com os usuários, contendo informações de contato ou um formulário para contato.

## 🛒 Carrinho

Página onde o usuário poderá visualizar os produtos adicionados, com possibilidade de remover itens e visualizar o total da compra.

## 💳 Pagamento

Página responsável pela finalização do pedido, simulando o processo de compra dos produtos selecionados.

## 🗺 Acompanhar Pedido

Página onde o usuário poderá visualizar o status do pedido, como “Em preparação”, “A caminho” e “Entregue”.

## 🧭 Navegação do site

A navegação será realizada por meio de um menu localizado no header do site, contendo acesso às principais páginas, como Home, Produtos, Sobre e Contato.

Além disso, haverá um botão localizado na lateral do header para acesso rápido ao Carrinho, facilitando a visualização dos itens selecionados pelo usuário.

## 👨‍💼 Área Administratativa (ADMIN)

### 🎟 Login Admin

Página de autenticação do administrador de acordo com cargo no banco de dados, caso não possua o cargo é redirecionado para a página home.

### 🖥 Painel Admin (DASHBOARD)

Exibe produtos cadastrados e Pedidos Recente.

### 🛍 Gerenciar produtos

Lista os produtos, opção de adicionar produtos. Excluir ou editar produtos já existentes.

### 🙋‍♂️ Gerenciar Pedidos

Lista os pedidos ativos / pendentes, permite visualizar o pedido e atualizar status.

### 🥇 Gerenciar Cargos

Lista os usuários e permite alterar os cargos de um usuário já existe no banco de dados.
